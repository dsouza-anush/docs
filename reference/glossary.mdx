## A

### Agent
An AI system that can take actions autonomously by calling tools, making decisions, and executing multi-step workflows. Agents go beyond simple chat by interacting with external systems.

### API Key
A secret token used to authenticate requests to the Heroku AI API. Stored in the `INFERENCE_KEY` environment variable.

## C

### Chat Completions
The primary API endpoint for conversational AI. You send messages, the model responds. Supports system prompts, multi-turn conversations, and streaming.

### Config Vars
Heroku's secure environment variables. Use these to store API keys and sensitive configuration instead of hardcoding them in your app.

### Context Window
The maximum amount of text (measured in tokens) a model can process in a single request. Claude models support up to 200K tokens, enabling analysis of very long documents.

### Cosine Similarity
A measure of how similar two vectors are, based on the angle between them. Values range from -1 to 1, with 1 meaning identical direction. Used in semantic search.

## E

### Embeddings
Numerical representations (vectors) of text that capture semantic meaning. Similar concepts have similar embeddings. Used for semantic search, RAG, and clustering.

**Example:** "happy" and "joyful" would have similar embeddings even though they're different words.

### Extended Thinking
A feature in Claude models that allows the model to "think" more deeply about complex problems by using additional internal tokens. Increases quality for reasoning-heavy tasks but costs more.

## F

### Fine-tuning
Training a model on your specific data to improve performance for your use case. Not currently available on Heroku AI - use prompt engineering instead.

### Function Calling
See [Tool Calling](#tool-calling).

## H

### Hallucination
When an AI model generates information that sounds plausible but is factually incorrect. RAG helps reduce hallucinations by grounding responses in real data.

### HNSW (Hierarchical Navigable Small World)
An index type for vector search that provides fast approximate nearest neighbor search. Recommended for most pgvector use cases.

## I

### Inference
The process of running a trained model to generate outputs (text, embeddings, images). "Inference API" = the API you call to get model outputs.

### Inference Key
Your API authentication token for Heroku AI. Found in your app's config vars as `INFERENCE_KEY`.

### Inference URL
The base URL for API requests. Points to your regional endpoint (e.g., `https://us.inference.heroku.com`).

### Input Tokens
The tokens in your prompt/request that you send to the model. You're charged for these.

## L

### LLM (Large Language Model)
A neural network trained on massive text datasets that can understand and generate human-like text. Examples: Claude, GPT, Llama.

### Latency
The time between sending a request and receiving a response. Lower is better. Haiku models have the lowest latency.

## M

### Max Tokens
A parameter that limits how many tokens the model can generate in its response. Use this to control costs and response length.

### MCP (Model Context Protocol)
An open standard for connecting AI models to external tools and services. Heroku supports MCP for custom tool integrations.

### Multimodal
A model that can process multiple types of input (text, images, PDFs). Claude Sonnet models are multimodal.

## O

### Output Tokens
The tokens generated by the model in its response. You're charged for these (usually at a higher rate than input tokens).

## P

### Prompt
The input text you send to the model. Can include system instructions, user messages, and conversation history.

### Prompt Caching
A feature that reduces costs when you send the same prompt prefix repeatedly. The cached portion is charged at a lower rate.

### Prompt Engineering
The practice of designing prompts to get better outputs from AI models. Includes techniques like few-shot examples, chain-of-thought, and structured formats.

## R

### RAG (Retrieval-Augmented Generation)
A pattern that improves AI responses by first retrieving relevant documents and including them in the prompt. Reduces hallucinations and enables knowledge-based responses.

**Flow:** User question → Search for relevant docs → Add docs to prompt → Generate answer

### Rate Limit
The maximum number of requests or tokens you can use in a time period. Prevents abuse and ensures fair resource sharing.

### Reranking
A technique to improve search quality by re-scoring initial search results based on semantic relevance to the query. Used after vector search for better precision.

## S

### Semantic Search
Search based on meaning rather than keywords. Uses embeddings to find content that's conceptually similar to the query.

**Example:** Searching "car problems" might return documents about "vehicle issues" or "automobile repairs."

### Streaming
Receiving model output as it's generated, token by token, rather than waiting for the complete response. Improves perceived latency for users.

### Structured Output
Getting AI responses in a specific format (usually JSON) that can be parsed programmatically. Achieved through tool calling or prompt engineering.

### System Prompt
Instructions at the beginning of a conversation that define the AI's behavior, role, and constraints. Not visible to end users.

## T

### Temperature
A parameter controlling randomness in model outputs. 0 = deterministic, 1 = more creative/random. Use lower values for factual tasks, higher for creative tasks.

### Token
A chunk of text that models process. Roughly 4 characters or 0.75 words in English. Pricing is based on tokens processed.

**Example:** "Hello, world!" = approximately 3-4 tokens

### Token Budget
The maximum tokens allocated for a specific purpose, like extended thinking. Controls cost and behavior for reasoning tasks.

### Tool Calling
Enabling AI models to invoke external functions or tools. The model outputs a structured request, your code executes the tool, and the result feeds back to the model.

### Tool Use
See [Tool Calling](#tool-calling).

## V

### Vector
A list of numbers representing data in multi-dimensional space. Used to store embeddings for similarity search.

### Vector Database
A database optimized for storing and querying vectors. pgvector adds vector capabilities to PostgreSQL.

### Vision
The ability of a model to process and understand images. Claude Sonnet models support vision for image analysis, OCR, and screenshot understanding.
